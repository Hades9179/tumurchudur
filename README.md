# 📚 Хурдан уншлага - Хүүхдийн Уншлагын Платформ

Энэ бол 10-16 насны хүүхдүүдэд зориулсан интерактив уншлагын вэб сайт юм. Хүүхэлүүд сайхан түүхүүдийг уншиж, аудио сонсож, сорилт шийдэх боломжтой.

## ✨ Үндсэн Функцүүд

### 👤 Хэрэглэгч Удирдлага
- ✅ Бүртгүүлэх/Нэвтрэх систем
- ✅ Хэрэглэгчийн профайл
- ✅ Уншлагын түүх

### 📖 Уншлагын Функцүүд
- ✅ 4 интерактив түүх
- ✅ 🔊 Web Speech API ашиглан монгол хэлээр аудио
- ✅ 🔵 Цэнхэр курсор Canvas-д хөдөлөх
- ✅ 📏 Фонтын хэмжээ сонголт
- ✅ Уншлагын хамт дүүжилж буй аудио

### 👨‍💼 Админ Панел
- ✅ Хэрэглэгчдийн удирдлага
- ✅ Түүхүүдэд өөрчлөлт оруулах
- ✅ Сорилтуудыг нэмэх
- ✅ 📊 Статистик харах

### 💾 Өгөгдлийн Сан
- LocalStorage ашиглан үйл ажиллагаа хадгалах
- Уян сэвсгээр ажилладаг

```
http://localhost:8000
```

## 🔧 Техникийн Онцлог

### Frontend
- **HTML5** - Семантик бүтэц
- **CSS3** - Gradient, Flexbox, Grid
- **JavaScript ES6+** - Асинхрон функцүүд
- **Canvas API** - Курсор зурах
- **Web Speech API** - Аудио функц
- **LocalStorage API** - Өгөгдлийн сан

### Дизайн
- 📱 Responsive design (мобайл, таблет, ПК)
- 🎨 Gradient өнгөүүд
- ✨ Анимаци
- 🌙 Сөнгийн дизайн
